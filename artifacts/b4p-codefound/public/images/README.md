# B4P image library

Images are grouped by how the website uses them:

- `conference/` — curated conference photography used across program and story pages.
- `drive/conference/` — the full Google Drive conference archive, including responsive variants used by the field gallery.
- `cwc/` — Columbus Women Connect brochure and community assets.
- `events/` — event posters, banners, and flyers.
- `stories/` — editorial story images.
- `supplied/events/` — browser-ready event images supplied for future event content.
- `supplied/field-photos/` — browser-ready JPEG copies of supplied HEIF field photos.
- `team/` — team portraits.
- `uploaded/` — approved homepage and page imagery.

Reference screenshots and design-only references stay in `attached_assets` and are not copied into the public website library.
